# Little Lemon Database Project - Meta Database Engineer Capstone

Repositori ini berisi proyek akhir (Capstone) untuk sertifikasi Meta Database Engineer dari Coursera.

## 📂 Struktur Repositori
- `/erd`: Berisi diagram ER (format PNG) dari MySQL Workbench.
- `/sql`: Berisi file skema database dan *stored procedures* (`little_lemon_db.sql`).
- `/python`: Berisi file Jupyter Notebook untuk koneksi Python dan manipulasi data.
- `/tableau`: Berisi file workbook Tableau dan tangkapan layar dashboard (`.twbx` & `.png`).

## ⚙️ Stored Procedures yang Diimplementasikan
1. `GetMaxQuantity()`
2. `AddBooking()`
3. `UpdateBooking()`
4. `CancelBooking()`
5. `ManageBooking()`
