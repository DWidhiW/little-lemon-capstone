# Little Lemon Database - Entity Relationship Diagram (ERD) Description

The ER diagram for the Little Lemon system includes the following main tables:
1. **Customers**: Stores customer information data (CustomerID, CustomerName, City, Country, ContactNumber).
2. **Bookings**: Stores table reservation data (BookingID, CustomerID, BookingDate, TableNumber).
3. **Orders**: Stores transaction order data (OrderID, CustomerID, BookingID, OrderDate, Quantity, TotalCost).
